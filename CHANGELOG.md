# Changelog

All notable changes to this project are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-10-16

### Changed
- New look: an analogue two-colour riso print (black and red ink on newsprint, the red plate a little out of register, halftone dots, paper grain). Replaces the night-sky collage, bats, moon and tape.
- Menu bar icon: a tapered mug with two fangs bitten out of the rim. Solid with steam when awake, outline when sleep is allowed.
- App icon, README art and the site redrawn in the same print. Helvetica Neue for all text; commands stay monospace.

## [1.0.0] - 2026-10-15

### Added
- Menu bar toggle that takes the same four power assertions as `caffeinate -dims`, through IOKit, with no child process.
- App Sandbox with nothing granted, hardened runtime, universal binary (Apple silicon and Intel), macOS 11 or later.
- Mug icon drawn in code as a template image: closed eyes when sleep is allowed, open eyes and rising steam when awake. The steam animation is skipped under Reduce Motion.
- Right-click menu: how long it has been awake, Keep Awake or Allow Sleep, Open at Login (macOS 13+), Quit.
- `--setup` turns on Open at Login and shows a one-time hint under the mug. `--remove-login-item` turns it off. `--check` is the self-test CI runs.
- `install.sh`: HTTPS only, pinned SHA-256, signature check, no sudo, installs to `~/Applications`, `--uninstall`.
- Release zips built by GitHub Actions from the tagged source, with a build-provenance attestation. Every action pinned by commit SHA.
- Mascot, app icon, hero and sandbox diagrams in light and dark, all generated by `assets/generate.py`.
